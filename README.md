# Bank Loan Analysis Dashboard

## Project Overview
This project analyzes bank loan data using Power BI to understand loan applications, funded amounts, repayments, and overall loan performance.

## Tools Used
- Power BI
- Data Visualization
- Data Analysis
- 

## Key Objectives
- Analyze total loan applications and funded amounts.
- Compare good loans and bad loans.
- Track loan status and repayment performance.
- Identify trends and patterns to support better lending decisions.

## Dashboard
The interactive Power BI dashboard presents key metrics, charts, and insights to help understand bank loan performance.

## Conclusion
This project demonstrates how data visualization can turn loan data into meaningful insights and support data-driven decision-making.
